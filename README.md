# Bea Nunes — Webpage 🐾

Página de divulgação do perfil do Instagram da **Médica Veterinária Beatriz Nunes** ([@beanunesn](https://www.instagram.com/beanunesn/)).

- 🏠 Consulta domiciliar de cães e gatos
- 📍 Rio de Janeiro e Baixada Fluminense
- ✨ *"Conforto para o pet, praticidade para você!"*

## Tecnologia

Site estático (HTML + CSS + JS puro), sem etapa de build. Hospedado via **GitHub Pages**.

## Estrutura

```
├── index.html              # página principal
├── assets/
│   ├── css/style.css       # estilos
│   ├── js/main.js          # interações (lightbox, scroll reveal)
│   └── img/                # fotos do perfil
└── README.md
```

## Como rodar localmente

Abra o `index.html` no navegador, ou sirva a pasta com:

```bash
python -m http.server
```

e acesse `http://localhost:8000`.
